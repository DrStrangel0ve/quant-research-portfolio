# 11 — Ruin and information games

**Question:** Do seeded simulations converge to exact conditional-probability
benchmarks?

The experiment compares Monte Carlo gambler's-ruin success with the absorbing
random-walk formula and verifies the one-third/two-thirds Monty Hall split.
Standard errors keep discrepancies in statistical context.

```bash
python projects/11_probability_games/run.py
```

These small games are useful quant interview exercises because they test state
conditioning, absorbing processes, simulation design, and falsifiable checks.
